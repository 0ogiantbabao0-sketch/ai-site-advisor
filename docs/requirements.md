# 現在の要件：ChatGPT用プロンプト作成ツール

ユーザーは無料で利用できる方式として「アプリでプロンプトを作り、ChatGPTへコピーして実行する方式」を選択した。

- エリア、対象日、機種、任意の調査先・希望からプロンプトを作る。
- 生成内容を表示し、コピーしてChatGPTで実行できる。
- APIキー・API課金・CSV・DB登録を不要にする。アプリから外部サービスへ入力を送らない。
- 実際の調査・採点・回答はChatGPT側で行う。無料プランの機能・利用制限はChatGPTに従う。
- Web検索できない場合は調査済みとせず、参照元や不明点を明示する指示をプロンプトへ組み込む。
- 黒・濃紺を基調にしたダークなスマホ画面。文言は必要最小限。
- GitHubの 0ogiantbabao0-sketch/ai-site-advisor に実装を保存する。
