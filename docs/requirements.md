# 現行仕様

- スマホ対応のダーク画面。
- エリア・範囲の目安・対象日・機種・希望条件を入力。
- 設定で調査プロンプトと最大5件の公開HTTPSページを保存。
- ボタンからPages Functionsへ条件とプロンプトを送信。
- サーバーの許可ドメインにある指定ページを取得しWorkers AIで比較。
- 結果、実際の取得URL、取得日時、取得失敗を表示。
- APIキー・DB・CSV不要。AIはCloudflare Freeの無料枠を利用。
- Web全体の検索、リンク巡回、JavaScriptページの実行はしない。
- 未取得情報は未確認、根拠不足は評価保留。AI参考スコアは勝率・利益の予測ではない。
- 利用パスワードをサーバーで検証。Secretsはクライアントへの配信・Gitへの保存をしない。
- プロンプト変更も、取得資料だけを根拠にするサーバーの調査方針の範囲で実行。
